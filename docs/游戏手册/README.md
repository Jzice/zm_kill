- **默认模式为掌门路（zml）**：修真牌堆 + 原著角色 + 修真资源层。
- **牌堆合计 226 张**（代码实算；设计稿早期目标 234 张，经拆分重分类后调整）。
- **角色池 61 人**（设计稿部分章节写“48 人”为旧数据，以代码为准）。
- 开辟战争（war）分队与灵地胜负判定、夺舍、家族族会、器灵成长等机制尚未实装。
