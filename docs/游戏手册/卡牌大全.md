# 掌门杀 · 卡牌大全（掌门路模式）

> 本表整理自 `src/data/zml/cards.zml.ts`，为**掌门路（zml）/ 开辟战争（war）** 模式的修真牌堆。
> 卡名与 `sub`（引擎结算键）一致，故出牌 / 判定 / 响应链 / AI 逻辑统一，不区分模式。

## 牌堆构成（代码实算合计 229 张）

| 大类 | 子类 | 张数 |
| --- | --- | --- |
| 基本牌 | 攻击（普通 / 烈火 / 雷霆）/ 防御 / 恢复 / 增益 | 58 |
| 锦囊（通用） | 15 种 | 47 |
| 锦囊（原著机制） | 5 种（诡代之法 / 本命代征 / 通明身识 / 全知天眼 / 筑基丹） | 9 |
| 锦囊（角色专属技能卡） | 19 种 | 19 |
| 装备 | 兵器 / 护身法器 / 载具 / 阵法 / 法宝 | 38 |
| 法宝·进攻 | 27 种（均进武器槽） | 27 |
| 法宝·防守 | 31 种（均进防具槽） | 31 |

> 注：当前代码实算 229 张（`ZML_DECK_TOTAL`）；本表以代码为准，与游戏手册其余分册、设计稿、冒烟脚本口径一致。
