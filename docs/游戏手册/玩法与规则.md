# 掌门杀 · 玩法与规则

> 本手册整理自 `src/` 引擎代码，覆盖掌门路（zml）/ 开辟战争（war）两种模式。
> 详细卡牌见《卡牌大全》，角色见《角色图鉴》，门派与主公技见《门派与主公技》。

## 一、游戏概述
掌门杀是一款浏览器端**身份推理卡牌对战**游戏，背景设定于《修真门派掌门路》的修真世界。
玩家各持一名角色（带天赋/技能），分配隐藏身份，通过出牌、攻击、技能与推理击败对手。

- 默认模式为 **掌门路（zml）**：修真牌堆 + 原著角色 + 修真资源层（灵石 / 境界 / 灵地 / 本命 / 家族 / 载具）。
- 开辟战争（war）在掌门路基础上按门派分队，以灵地占领为胜负目标（分队与灵地胜负判定尚在后续迭代中，本构建未完全实装）。

## 二、对局模式

### 胜负判定（`checkWin`，`src/game/damage.ts`）
1. **掌门阵亡**：
   - 若邪修已全部阵亡、仍有黑手存活、且场上仅剩该黑手一人 → **黑手获胜**。
   - 否则 → **邪修获胜**。
2. **邪修与黑手全部阵亡** → **掌门与弟子获胜**。
3. 对局结束自动揭示所有角色身份（含存活者）。

> 注：设计稿中提到的「黑手夺舍」（阵亡时夺舍一名存活角色）在**本构建未实装**，当前黑手按经典内奸规则取胜。

## 四、回合流程（`runTurn`，`src/game/turn.ts`）

每名存活角色的回合依次经历：

1. **翻面检查**：若处于翻面状态，跳过整个回合并翻回正面（与混元剑狱的「横置」相互独立）。
2. **重置本回合状态**：清空【攻击】使用次数、技能已用、跳过标记、增益加成等。
3. **觉醒判定**：触发觉醒技（如赵瑶【入魔】、展剑锋【入劫见真】）。
4. **辐射标记结算**：结算持续标记。
5. **准备阶段（onTurnStart）**：触发准备类天赋/主公技（摸牌、距离、回复等）。
6. **判定阶段**：结算延时锦囊（七星定身阵 / 哼哈真言 / 天劫）。
7. **灵石产出**（仅掌门路）：基础产出 + 已占灵地产出。
8. **摸牌阶段**：基础摸 2 张 + 额外摸牌（天赋/装备/主公技）；哼哈真言跳过。
9. **出牌阶段**：可使用【攻击】/【防御】/【恢复】/【增益】/锦囊/装备，发动主动天赋与主公技，以及掌门路专属修真行动（坊市 / 突破 / 开辟灵地）。
10. **弃牌阶段**：手牌超过上限须弃至上限。
11. **回合结束**：触发结束类效果，清理本回合到期的诡代复制天赋。

## 五、距离与攻击范围
- **攻击范围** = 装备武器时的 `range`（无武器默认为 1）**+ 天赋的「攻击范围 +n」加成**（如参宿星、蜂云剑阵、星遁；`rules.ts` `attackRange` → `talentEngine.rangeBonusOf`）。
- **座位距离**：按座位顺时针 / 逆时针的较短座位数。
- **载具 / 法器修正**：
  - 进(−1) 载具（乙木御风梭等）：**你**计算与其他角色的距离 −1（你能打到更远的人）。
  - 守(+1) 载具（虾驼兽等）：**其他角色**计算与你的距离 +1（别人更难打到你）。
  - 部分天赋（如清风大道、龙家）令你计算距离 −1；部分（如楚老祖、兽王领地）令他人与你距离 +1。
- **防守距离**：技能文中「其他角色计算与你的距离 +n」（原语 `distPlusToMe`）即**防守距离 +n**，与守(+1) 载具叠加；「攻击距离 +n」（原语 `rangePlus`）即攻击范围加成。
- 攻击范围仅影响【攻击】与部分需要“攻击范围内”的牌；锦囊（如敛息诀/破阵符）按各自距离规则。
- ⚠️ **本版修复**：早前 `attackRange` 只取武器数值、漏加天赋加成，导致全部「攻击范围 +n」天赋（含齐云主公技【天地独尊】、青莲剑宗主公技【剑心通明】）实际不生效；现已修复，相关角色攻击范围会较旧版变大。

## 六、手牌上限与弃牌
- **基础手牌上限 = 当前体力值**（受伤后上限随之降低）。
- 法宝 / 天赋可提升上限（如储物袋 +2、开山立派 +2、神傀化身 +2 等）。
- 弃牌阶段超过上限须弃至上限；法宝/天赋的“置于牌堆顶”弃牌优先于弃入弃牌堆。

## 七、修真资源层（仅掌门路 / 开辟战争）

### 灵石
- 上限 **8**（溢出作废）；回合开始基础 +1；每块已占灵地按阶产出（占领 >2 块后每块 −1，最低 1）；击杀 +2。
- 消耗：坊市（3 灵石摸 1 张，每回合限 1 次）、境界突破、开辟灵地（2 灵石）、红玉阵盘抵消伤害。
- 灵石**不可被抢夺**。

### 修为（经验）
- 来源：造成伤害 +1 / 击杀 +2 / 救活 +1 / 占领灵地 +1 / 悟道 +1（每回合限 1 次）/ 服用【筑基丹】+2。
- 用于境界突破。

### 境界与突破（`BREAKTHROUGH`）
| 当前境界 | 需灵地阶 | 需灵石 | 需修为 | 上限+ | 回复 |
| --- | --- | --- | --- | --- | --- |
| 练气→筑基 | 1 阶 | 3 | 4 | +1 | +1 |
| 筑基→金丹 | 3 阶 | 6 | 8 | +1 | +1 |
| 金丹→元婴 | 5 阶 | 10 | 12 | +2 | +2 |
| 元婴→化神 | 5 阶 | 14 | 16 | +2 | +2 |
| 化神→炼虚 | 5 阶 | 18 | 20 | +2 | +2 |
- 每局最多突破 **3 次**；需“灵地 + 灵石 + 修为”三者齐备方可突破；突破提升体力上限并回血。
- 突破在出牌阶段以「🆙突破至【境界】」按钮触发。
- **破境机缘**：突破成功后二选一 —— 从天赋池再觉醒 1 门天赋，或体力上限 +1 并回 1 点体力。

### 灵地
- 开局按人数生成无主灵地盘：4~5 人 3 块、6~8 人 5 块、2~3 人 2 块（取自楚秦山、黑河峰、剑影山、白塔城等真实山门地名）。
- 出牌阶段付 2 灵石可**开辟**一块无主灵地，得 1 修为；占领后每回合按阶产出灵石。
- 本命越多（灵根越杂）修炼越慢：修为需求已在突破表中体现。

### 坊市
- 出牌阶段付 3 灵石摸 1 张，每回合限 1 次。

### 悟道
- 出牌阶段每回合限一次，修为 +1（用于凑够突破所需修为）；对应按钮「🧘悟道」。

### 本命 / 灵根
- 每名角色带 `benming`（1~2 个），对他人**隐藏**；阵亡或被【全知天眼】探查后公开。
- 探听本命即结怨：被探查者对探查者敌意 +1（AI 记仇）。

### 家族血脉
- 角色带 `family`（齐 / 秦 / 楚 / 展 / 熊 / 莫 / 南宫 / 龙 / 霍 …），为后续「族会」等机制预留（本构建未实装）。

## 八、装备槽位
每名角色有四个装备位：**武器 / 防具 / +1 载具（守）/ −1 载具（进）**。
- **法宝**不是独立槽位：按 `equipSlot` 进武器槽（进攻型）或防具槽（防守型）。
- 装备武器后触发“装备后”天赋（如莫剑心【成剑】）。
- 更换装备时旧装备进入弃牌堆（防具触发失去效果）。

## 九、技能（天赋）类型
角色天赋分多类（`kind`）：
- **被动 passive**：满足条件自动生效（如摸牌阶段额外摸牌、手牌上限 +、距离修正、伤害增减、减伤）。
- **主动 active**：出牌阶段以按钮发动，多带“限一次 / 每回合”限制。
- **触发 trigger**：在指定时机自动触发（受伤害后、使用锦囊后、阵亡时等）。
- **转化 convert**：可将某类手牌当【攻击】/【增益】/【恢复】/【破阵符】使用（如诡代、器符城铸剑）。
- **限定 limit**：整局仅一次（如莫剑心【以身饲剑】、醒狮【昏睡】）。
- **觉醒 awaken**：满足条件后减体力上限并获得强化天赋（如赵瑶、展剑锋）。
- **主公技 lord**：仅掌门获得，见《门派与主公技》。
- **天赋池**：每名角色持 4 门左右天赋组成的「天赋池」；开局随机激活 2~3 门生效（池 ≤3 时全激活），其余留待境界突破时觉醒。

### 本命法宝与升级天赋（角色升级机制）

角色天赋分两套：**天赋池**（上面的随机激活 / 破境觉醒）与**升级天赋**（本节的装备解锁）。两套互不干扰。

- **升级天赋不进天赋池**：不会被开局随机抽到，也不占破境机缘名额；对应角色即使没抽到本命天赋，只要装备了本命法宝，依然能解锁进阶技能。
- **本期解锁条件 = 装备**：装备对应法宝当刻自动获得并写入战报（`🗡️ 得法宝之助，解锁【X】`）；法宝被**替换 / 拆掉 / 夺走**当刻立刻失去（`🗡️ 失去法宝加持，【X】失效`）。
- **角色 + 卡名双重匹配**：法宝只对「本命对应角色」生效。他人装备幻星无形剑不会解锁秦长风的星遁；同名多张重复装备幂等，不会叠加。
- **日 / 月 / 星 / 影四剑**（原著莫剑心以身饲剑所铸，四阶无形剑，各 1 张、随牌堆抽取）：

| 法宝 | 归属角色 | 解锁技能 | 效果 |
| --- | --- | --- | --- |
| 幻日无形剑 | 齐休 | 【五感剥夺】 | 出牌阶段限一次：弃 1 张手牌，令一名其他角色**翻面**（跳过其下个回合） |
| 幻星无形剑 | 秦长风 | 【星遁】 | 攻击范围 +2，且其他角色计算与你的距离 +1（防守距离 +1） |
| 幻月无形剑 | 齐妆 | 【月华】 | 手牌上限 +1；不能成为【破阵符】【敛息诀】的目标 |
| 幻影无形剑 | 楚无影 | 【影遁】 | 计算与其他角色的距离 −1；手牌上限 +1 |

- **其它解锁条件**：「丹药」（服用指定丹丸）/「悟道」（境界达标）已在数据层（`TalentDef.unlock`）预留，后续版本开放。
- **实现**：条件写在技能定义上（`src/data/zml/upgradeTalents.zml.ts`），由 `src/game/zml/upgrades.ts` 的 `syncEquipmentUpgrades` 在装备变动（出牌装备 / 弃置 / 夺取 / 劫夺 / AI 装备 / 局前配装）时幂等增删 `Player.talents`，并经 `state_sync` 同步给联机客户端。

## 十、属性攻防（仅掌门路 / 开辟战争）

属性攻防仅作用于掌门路 / 开辟战争；伤害结算与属性逻辑由 `isZml` 守卫，与无属性场景严格隔离。

由两层属性构成，均作用在**伤害数值**上，不改动既有减伤 / 护盾 / 铁索逻辑（`src/data/zml/attr.ts` + `src/game/damage.ts`）：

### 1. 道统（角色对角色）

### 3. 伤害计算顺序

`base`（攻击伤害 / 天赋伤害）
→ 既有火雷减伤（免疫、阴阳大道）
→ 既有防具技能（清风法袍 / 映雪冰风阵 / 明光铠 / 玄水阵盘 / 红玉阵盘）
→ 局前护甲、必杀加成
→ **道统加成（±1）**
→ **卡牌属性加成（±1 或判定）**
→ 护盾吸收 → 扣血 → 混元剑狱传导

- 最终伤害 **不低于 0**；若结果 ≤ 0 则本次不造成伤害（战报记「被属性 / 道统加成完全抵消」），**不触发命中后效果**（武器追加、受伤后技能等）。
- 混元剑狱传导沿用原「同属性同数值」规则，传导伤害无来源，不再叠加道统 / 属性加成。

### 4. 卡面徽标

手牌卡面左下角显示属性徽标、右下角显示道统徽标；出牌区与座位名旁同样显示（掌门路 / 开辟战争均渲染）。配色：金 / 木 / 水 / 火 / 土 五色，雷 / 兽 / 道德 / 鬼物 / 风 / 毒 各有专色，道统六色（道 / 佛 / 儒 / 魔 / 鬼 / 外道）。

## 十一、其它规则要点
- **拼点**：部分天赋（舌战、分庭抗礼、言魅之术）需与目标拼点，比点数大小。
- **延时锦囊**：七星定身阵（跳出牌）、哼哈真言（跳摸牌）、天劫（雷伤）在判定阶段结算。
- **改判**：主公技【崇理】、天赋【断劫雷】【阴阳大道】、法宝【通明幻镜】可在判定牌生效前用手牌替换。
- **混元剑狱 / 属性伤害传导**：混元剑狱横置的角色间，火/雷属性伤害互相传导；映雪冰风阵等对其有抗性的防具需注意。
- **群攻锦囊**：魔灾泛起（需【攻击】抵御）、万剑钻心（需【防御】抵御）对所有其他角色生效。
- **命演术（身份洞悉）**：指定一名其他角色，该角色翻判定牌——♥红桃则你**私下**查看其隐藏身份（仅你可见，他人无从得知）；未生效则无事发生。使用者**失去 1 点体力**，且每名角色**每局只能使用一次**；体力不足 2 点时不可使用。
- **夺舍 / 开辟战争分队 / 家族族会 / 器灵成长 / 飞蟹载客** 等机制在**设计稿中规划，本构建尚未实装**。
