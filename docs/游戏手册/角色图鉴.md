# 掌门杀 · 角色图鉴（掌门路原著角色池 · 61 人）

> 整理自 `src/data/zml/characters.zml.ts` 与 `src/data/zml/talentdefs.zml.ts`、`src/data/zml/talentdefs.pool.ts`。
> 体力为角色基准值；若担任**掌门（主公位）** 则体力上限 +1。
> 境界：练气 / 筑基 / 金丹 / 元婴 / 化神（局内修炼最高至炼虚）。

## 天赋池机制（v1.4 重做）

- 每名角色持有 **4 门左右**的「天赋池」（基础天赋 2~3 门 + 扩展天赋 1~2 门，扩展部分见 `talentdefs.pool.ts`）。
- **开局随机激活**：天赋池 >3 时，随机激活 **2~3 门**本局生效，其余记入「天赋池剩余」，开局战报会公布；池 ≤3 时全部激活。
- **破境机缘**：掌门路模式境界突破成功后，二选一 —— 「再觉醒 1 门天赋池天赋」或「体力上限 +1 并回 1 点体力」。
- **新增突破途径**：出牌阶段「悟道」每回合限一次、修为 +1；【筑基丹】服用后修为 +2（牌堆 +3 张）。
- 下文各角色条目仅列**基础天赋**；其扩展天赋（名称 / 效果）见 `talentdefs.pool.ts` 与角色定义处的 `POOL_EXTRA`。
- **升级天赋**（v0.1.7 新增）：不属于天赋池、不参与开局随机、不占破境机缘名额，只由「装备本命法宝（丹药 / 悟道预留）」条件解锁，法宝离身即失效 —— 详见《玩法与规则》「本命法宝与升级天赋」。条目中以 **🗡️ 升级** 标注。
