# 开辟战争

## 基本信息

- **事件类型**：系列性战争（由大周书院周期性发起）
- **时间跨度**：贯穿全书，最早见于第013卷（白山深处开辟战争），延续至第021~025卷（小魔渊、酆水、醒狮谷、外海、死亡沼泽等）
- **地点**：此界各处蛮荒地带（白山深处、小魔渊、酆水流域、醒狮谷、外海、死沼等）
- **关键势力 / 人物**：
  - 发起与主持：大周书院（此界之主，主导再分配）
  - 常参战方：齐云派、白山密宗、御兽门、丹盟、灵木盟、器符城（祁无霜）、楚秦门（多任后勤运输）、各参战宗门 / 家族 / 散修
- **结局**：蛮荒古兽领地荡平、分封为"熟地"，催生新宗门 / 修真家族；战后必伴随大规模骚乱（规律性次生灾害）

---

## 背景

"开辟战争"是大周书院主导的、周期性的大规模战争，目的并非"开宗立派"本身，而是**清剿蛮荒古兽、将未开发之地变为可分封的"熟地"**（第270章）。

其触发逻辑（第270章）：
1. 当大量修士同时产生开宗立派 / 成立修真家族的欲念，说明人类地盘不够用、内部竞争过烈；
2. 与其内耗，不如从蛮荒存在手中抢夺；
3. 大周书院需平衡各方利益、凑足参战动力，方能发动——否则不会"发现此界无数年，才开发了不到百分之一"。

参战各方换取**功绩点**，凭此换取开宗立派资格、正式修真家族资格、山门领地、通天令等（第270章）。

> 注：此"开辟战争"须与"上界开辟此界"（世界起源，见 `K-01 此界开辟.md`）严格区分。后者为一次性原初事件，本档案只处理前者。

## 经过（按时间线梳理）

### 白山深处开辟战争（第013~014卷，楚秦门南迁第65年起，齐休94岁）
- 大周书院、齐南城（齐云派）、白山密宗三化神锁定白山深处化神级蛮荒古兽（一头"脾气温和"的母象），标志战争爆发（第270章）
- 首应者丹盟（新晋元婴，欲成白山第十大势力）、次应者灵木盟（失蛮荒接壤之利难承）、祁无霜（报灵木盟之恩）、蒯家与楚秦门（人情债）（第270章）
- 齐休讨价还价，楚秦门争取到后勤运输肥差，租御兽门银背驮鳐共七艘，往返前线发战争财（第270章）
- 战争持续约十年：第八年北线第五只元婴古兽死；第九年夏三化神（大周书院、齐云、白山密宗）联手击杀化神古兽，夺白山深处唯一四阶灵地**银象山**；年末北线与东线会师，大局已定
- 战后大赏功，楚秦门因后勤之利壮大；然近万外来修士失约，啸聚为流寇，引发次生大乱（第283章战后大赏功）
- 白山深处开辟战争（第013~014卷主体）目前尚无独立 W 类档案，建议后续补建 `W-10` 以与 W-01~W-09 体例对齐

### 小魔渊开辟战争（第019~020卷，约第490~500章）

### 酆水流域开辟战争（第020~021卷，第518~550章）

## 结果与影响

1. **地缘重塑**：每一次开辟战争都将蛮荒变为熟地，催生新势力（如丹盟欲借机成白山第十大势力），同时改变势力格局。
2. **规律性次生灾害**：开辟战争后必有大规模骚乱——参战失意修士啸聚为流寇，战场周边最弱者（如楚秦门）首当其冲（第270章）。
3. **大周书院主导权**：作为此界之主与开辟发起者，大周书院借此维系对各界域的再分配控制权；御兽门凭"独立发动开辟战争"的特权，成为最强宗门之一（见 `上八门.md`）。
