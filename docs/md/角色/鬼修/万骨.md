# 万骨

| 项目 | 内容 |
|------|------|
| 姓名 | 万骨（原名精细鬼） |
| 性别 | 男 |
| 修为 | 筑基~金丹（鬼修），前世拥有空间大能级修为 |
| 本命 | 无（鬼物无本命） |
| 势力 | 鬼修/散修 |

## 别名/称号

- **精细鬼**: 原名，在另一界时的称呼（第608章：精细鬼嫌"名字后面带个鬼字"不好听）
- **万骨**: 自己改的名（第608章：精细鬼自己说"以后，我便改名唤做'万骨'如何？"）
- **万骨老鬼**: 姜炎对其的称呼（第427章）
- **空间大能**: 齐休对其前世修为的判断（第654章）

## 外形描述

- **3000多年前（全知神宫回溯）**: 整个身子被黑色斗篷罩住，身量极矮（约正常人身高的一半），不辨面目，背后肩胛骨位置伸出银色锁链被姜家元婴牵着（第608章）
- **第339章（试炼之地）**: 身着齐云道袍的壮汉形态，声音苍老嘶哑，"桀桀"笑声，毫无生气，是纯鬼物
- **第405章（死亡沼泽归来）**: 鬼蛛形态，黑色身体油亮结实
- **第427章（北丁申山探索）**: 鬼蛛形态，千目复眼
- **第654章（袭杀齐休）**: 全身藏于黑色斗篷中，与3000多年前造型相似，声音嘶哑豺声，比3000年前苍老许多

## 能力与法宝

### 空间之力（前世核心能力）
- 能配合阵法驱使空间之力，搭救被墨蛟攻击的修士（第609章回忆）
- 能施展空间禁制束缚敌人行动（第654章）
- 齐休认为其三千多年前"可以操纵那么大空间变化"（第654章）

### 鬼修手段
- 土中穿行秘法（第427章）
- 神妙的感应能力和寻路技术（第427章）
- 吸取阴尸之气修炼（第405章）
- 黑风鬼道之术（第339章）
- 以阵破阵之能——用收集的破烂材料拼凑成阵法破玉壁（第430章）

## 主要事迹

### 3000多年前：被姜家元婴带到此界（第608-609章，全知神宫回溯）

- 精细鬼原是另一界的鬼物/凶物，被齐云姜家一位元婴老祖带到此界
- 被姜家元婴以银色锁链锁住，如牵狗一般
- 参与齐云、白山联手除灭墨蛟之战，在阵中以空间之力专门搭救躲不开墨蛟攻击的修士
- 见识到此界众多仙人术法宝物后非常兴奋，要求"长留此界"
- 嫌自己原名"精细鬼""名字后面带个鬼字"不好听，自己提议改名为**"万骨"**
- 姜家元婴假意答应，实则背地里暗暗结印准备杀人灭口
- 事后以佛门辟邪手段骤下杀手，精细鬼被法印笼罩，无声无息被诛灭当场
- 佛光消散，只余一件空空如也的黑色斗篷
- 但精细鬼留下残魂，藏身于**姜云山中一个普通小鼎**里，等待有缘之人（第609章）

### 第339章：试炼之地首次现身（壮汉形态）

- 姜炎在楚秦试炼之地筑基后，派精细鬼去杀多罗诺灭口
- 精细鬼以壮汉形态现身，自称"万骨"，修为筑基初期，纯鬼物
- 多罗诺以镇尸铜钱等物抵抗，全然无用
- 正要得手时，被一只突然出现的**巨大鬼蛛**打断——鬼蛛吐出鬼气缠丝将壮汉捆住，往漆黑巨口里拖动
- 壮汉连施手段欲挣脱，鬼蛛却更胜一筹
- 多罗诺趁机逃走，称"狗咬狗"

### 第340章：姜炎的反应

- 姜炎以为精细鬼已死（实际上被鬼蛛吞下）
- 后发觉精细鬼还活着，两者建立了某种联系

### 第350-355章：与齐休的关联

- 齐休与姜炎谈判时提到精细鬼（第350章）
- 南宫家将"万骨"作为谈判筹码提及（第355章）

### 第405章：鬼蛛形态重现

- 万骨以鬼蛛形态出现，从死亡沼泽归来
- 中气更足，鬼蛛身体愈发油亮结实
- 搬运尸体，将尸体搬入狭缝法阵中，贪婪吸取阴尸之气
- 称死亡沼泽"不能久呆，否则就会被上瘾同化，变成无灵魂的真'死人'"

### 第427-430章：北丁申山地下探索

- 万骨以鬼蛛形态和姜炎一起探索北丁申山地底迷宫
- 以土中穿行秘法和神妙感应能力在前探路
- 姜炎称其为"万骨老鬼"，问其以前是干什么的
- 万骨感慨"往事不堪回首"，从不谈论过去
- 最终在地底极深处找到一道斑驳玉壁
- 玉壁是人为造就，被万骨用破烂材料拼凑的阵法以阵破阵（第430章）
- 姜炎问其从前到底是什么修为，万骨答："我说我曾独掌一方世界，你信么？"
- 姜炎说信，万骨随即否认："你信？哈哈，我自己都不信。刚才那话，是骗你这种小孩子的，我当然从没曾真正的独掌过一方世界……我只是个鬼修，也一直是个鬼修"
- 玉壁后有逃亡生路

### 第469章：蒙山夹缝探索

- 与齐休、姜炎三人一起探索蒙山夹缝

### 第525/532章：归古派追捕

- 归古派将追捕姜炎、万骨与何玉并列为重要任务（第525章）
- 贾长庚提及万骨，列为下落不明者之一（第532章）

### 第654章：袭杀齐休

- 姜炎（金丹圆满）携万骨袭杀齐休于楚恩山同参殿
- 万骨以空间禁制配合姜炎，令齐休行动迟缓
- 齐休通过见人性天赋得知"万骨老鬼"的存在：**万骨残魂藏于姜云峰内一个普通小鼎之中，被姜炎偶然召唤出来后便一直陪伴其左右**
- 齐休认出万骨就是当年被姜家元婴锁拿暗害的精细鬼，"来自另一界的空间大能"
- 万骨发现齐休能在其空间禁制下行动自如，大为惊讶
- 催促姜炎速战速决："你这干外公有些本事！快！外面人已赶过来了！"
- 齐休最终逃过一死

### 第660章/第670章：间接提及

- 盟主感谢词中提到"万骨大帝"（第660章）
- 姜炎有"万骨老鬼帮衬"的旁证（第670章）

## 势力范围归属

- **活动区域**: 姜云山→试炼之地→死亡沼泽→北丁申山→蒙山→楚恩山
- **前世归属**: 另一界的鬼物/凶物
- **关联势力**: 姜炎（长期搭档）、齐云姜家（仇敌）

## 设定关联

- **空间神通**: 万骨前世身为空间大能，能以空间之力搭救修士、布置空间禁制，是全书少有的空间属性存在
- **全知神宫/墨蛟**: 万骨参与过3000多年前的诛墨蛟之战，其空间之力在战中起了关键作用
- **姜炎线**: 万骨是姜炎最重要的鬼修搭档，从姜炎筑基期一直陪伴到金丹期
- **跨世界设定**: 万骨来自另一界，为此界的跨世界关联提供了证据
- **鬼物修行**: 展示了鬼物通过吸取阴尸之气和死亡沼泽之力修行的设定
- **死亡沼泽**: 万骨曾深入死亡沼泽，认为"不能久呆"否则会被同化

## 备注

1. "精细鬼"是其在另一界时的原名，"万骨"是他自己改的名（第608章），非姜家元婴所改
2. 第430章"曾独掌一方世界"的自语先自夸后否认，真伪存疑
3. 万骨被同一姜家元婴灭口，却留下残魂藏于小鼎，后被姜炎偶然召唤（第654章）
4. "万骨大帝"一说仅在第660章盟主感谢词中一闪而过，身份不明
5. 万骨对姜炎的过去（母亲被杀等）了如指掌，是其最信任的搭档和军师
