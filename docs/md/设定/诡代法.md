# 诡代之法

> 楚秦门核心传承功法。本文档独立梳理「诡代之法」的源流、路径、风险与修炼者，基于小说原文标注具体卷号章节。其对照概念「本命代征」见 [本命代征.md](本命代征.md)（二者为两种根本不同的本命认知方式，第583章《玉鹤论大道》中玉鹤明确区分）。

---

## 一、概述

诡代之法乃楚秦门已故金丹前辈**楚慧心**所创，用以解决「废本命 / 沉睡本命」修士无法修行的问题。其核心本质为：**将真实本命诡代成其他（以假代真）**——以同参之物为媒介，观想出一个"假本命"（诡代本命），借二者共通特性间接带动真本命，增进修为。

**首次出现**：第4卷·第61章《祸兮福所倚》（楚夺传法）

**与本命代征的根本差异**（第583章玉鹤原话）：
> "这诡代之法，乃是将真实本命诡代成其他。而本命代征，则是原来本命无法具象呈现，识海中的，乃是一个代征物的形象。"

一言以蔽之：**诡代之法是"向外找替代"，本命代征是"向内破迷障"。**

## 三、修行路径：借假修真

```
废本命 → 以同参之物为媒介 → 观想"假本命"（诡代本命）
  → 假本命与真本命有共通特性 → 修炼假本命
  → 借助共通特性间接带动真本命 → 增进修为
  → 获得派生本命天赋
```

**关键表述**（第4卷·第61章）：以同参之物（如玲珑塔）为媒介，修炼时描绘一个"假本命"（诡代本命），假本命与真本命有某些共通特性，通过修炼假本命→借助共通特性→间接带动真本命→增进修为。

## 四、本命状态与修炼者

| 修炼者 | 真本命               | 状态                 | 诡代本命                       |
| ------ | -------------------- | -------------------- | ------------------------------ |
| 楚慧心 | 废本命               | 完全不可用           | 未知                           |

| 楚无影 | 黑白色气团           | 废本命，无法正常修行 | 万影阁                         |

**特点**：真本命不可用或沉睡，需以假本命替代驱动修行。

## 五、风险

1. **结婴危机**（第24卷·第658章楚无影发现）：
   - 诡代之法结婴的本质不是"结婴"而是"孵化"
   - 诡代本命 = 本命原主的一缕"分魂种子"
   - 结婴"成功"那一刻 → 分魂觉醒 → 反客为主 → 吞噬修士神魂
   - 实质：原主通过分魂获得一次"借体重生"
   - 若原主还活着，可"遥控"结婴者
2. **三条破解路径**（据推断分析）：
   - 影化元婴道（楚无影）：完全绕过诡代之法
   - 不灭生机同化（齐休）：以命演术和赤尻马猴不断校准同化
   - 强行压制（白山新晋化神）：最终仍会被吞噬
3. **认知风险**：创始人楚慧心仅金丹修为，对结婴仅有模拟与想象。
