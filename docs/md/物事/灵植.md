# 灵植资料整理

> 说明：原文标题含“按品阶”“按种类”，正文提供“灵植列表”和“灵植一览表”。以下据原文汇总整理，未标注字段以“—”表示，不另行编造。

## 一、按品阶汇总

- **无阶**：乌心荷花、血罟根
- **一阶**：幽影树、养心草、凝气草、狼毒草、回春草、乌茎泽兰、霸竹、玄阴草、阳符草、人参
- **二阶**：烈炎草、木葵、青玉灵树、冰盏花、寸葛草
- **三阶**：朱香果、龙息花
- **四阶**：鬼面黑水藤、长生苔
- **五阶**：万年榕木妖、影木妖、漆山岛花妖
- **？阶**：沙棘草、养魂木、魔阴树、食人花妖、食人花木精、大丹果、人参果、兰槐蕨花、葫芦状白果

## 二、按种类汇总

- **灵树**：幽影树、青玉灵树
- **灵草**：养心草、凝气草、狼毒草、回春草、乌茎泽兰、玄阴草、人参、烈炎草、寸葛草、沙棘草
- **灵竹**：霸竹
- **纸草**：阳符草
- **木妖**：万年榕木妖、鬼面黑水藤、影木妖
- **灵花**：木葵、冰盏花、兰槐蕨花、龙息花
- **苔藓**：长生苔
- **花妖**：漆山岛花妖、食人花妖
- **植物**：乌心荷花、血罟根
- **灵木**：养魂木
- **魔树**：魔阴树
- **木精**：食人花木精
- **灵果**：朱香果、大丹果、葫芦状白果
- **异宝**：人参果

## 三、灵植一览表

| 名称 | 种类 | 品阶 | 相关 | 介绍 |
|---|---|---|---|---|
| 幽影树 | 灵树 | 一阶 | 秦唯喻、沙诺 | 全黑植物。在幽影岛上形成了丈许方圆，多少万年没被阳光照过的林中幽地[1]。后成为秦唯喻养魂地[2]。 |
| 养心草 | 灵草 | 一阶 | 多罗森 | 多罗森本命。花呈白色，是制作一阶清心丹的原料。见三木回心阵。[3] |
| 凝气草 | 灵草 | 一阶 | 多罗森 | 多罗森本命。花呈蓝色，是制作一阶回气丹的原料。见三木回心阵。[3] |
| 狼毒草 | 灵草 | 一阶中品 | 黄韶能 | 有毒性，边角种上可隔绝蚊虫鼠蚁，保护其余花草不受侵害。一年两收，是制造施毒类符篆符纸的原料，比阳符草稍贵一些。[4] |
| 回春草 | 灵草 | 一阶下品 | 多罗森、张胜男、阚缺 | 张胜男、多罗森本命，阚缺同参。花呈红色，是制作一阶回血丹的原料。见回春草阵、三木回心阵。[3] |
| 乌茎泽兰 | 灵草 | 一阶下品 | 秦唯喻 | 半人来高，由于枝干是黑色，经常被人误会是小树[5]。见乌茎泽兰阵、乌茎泽兰八卦迷阵。 |
| 霸竹 | 灵竹 | 一阶 | 黄韶能 | 没产出，能锁灵气，制造出阴凉之地种植其他作物[4]。草堂四周种植高高的霸竹，灵气被霸竹固化，缓缓向下沉淀，使修炼的速度还能更快些[6]。 |
| 玄阴草 | 灵草 | 一阶中品 | 黄韶能 | 能提升阴气，长势极快。一年一收，一株值一枚二阶灵石，必须及时补种。[4] |
| 阳符草 | 纸草 | 一阶 | 黄韶能 | 制造一阶火、光等阳属性符纸的主要原料。好养活，合适向阳坡地。像韭菜，当年就有收获，以后一年能收几茬，比一年一收的灵谷好赚得多。器符盟对制造各种符纸的原料需求惊人，不愁卖不出价钱。[4] |
| 人参 | 灵草 | 一阶上品 | 黄韶能 | 主要长在地下，喜阴凉。或五年收，或十年收，十分灵活，想五百年一千年收都可，按照年份算钱，越老越贵，平时不用去管，就一直存在那里，有需要用到它，或者急需灵石的时候再挖出来换钱，大小宗门，都喜欢养些人参，首乌之类，流传后世，算是给子孙后代留下的财产。[4] |
| 烈炎草 | 灵草 | 二阶中品 | 鲁平、蒋鸿苦 | 种下一年可长半尺高，由抽芽时的绿色，整株开始转变成淡红。这种火属性灵草有很强的侵略性，大部分品种的灵草，都无法在它旁边生存。漆黑的夜里，它还会发出淡红色的微光，随风轻摆，如血海浮动[7]。这是一阶上品烈炎丹的主料，一粒只需要用到一点。楚秦门比外面单价低半成独家卖给灵药阁蒋鸿苦[8]。 |
| 万年榕木妖 | 木妖 | 五阶 | 楚红裳、灵木盟 | 相当于金丹后期修为，思过山之战时从博木城被移植到秀山山顶，柴屏把楚红裳传送到榕木妖体内暂时困住过。战后凝有五阶万年榕木心，齐休封印收起，留给多罗森结丹后做法宝的器灵。[9][10][11] |
| 木葵 | 灵花 | 二阶中品 | 黄韶能 | 可与人参按一比一比例交杂密集种植，最大限度利用地力，两者十分互补。三年一收，一株一个大花骨朵，两到三朵能换一枚三阶灵石。[4] |
| 青玉灵树 | 灵树 | 二阶 | 空问、区豹 | 齐休血洗青溪山所得五百年二阶树，树下是他门中秘库所在，全身材料值一百多枚三阶灵石[12]。挖回仙林坳被空问救活。空问在树下结一个没顶的草庐，将小金养在树下[13]。大屠仙林坳时做诱饵，围攻的两位筑基后期为之大打出手[14]。被区豹抢走炼成粗陋不堪，最多一阶中品的青玉屋，作为自家修行居所[15]。 |
| 冰盏花 | 灵花 | 二阶上品 | 黄韶能 | 喜阴。七年一收，一朵一枚三阶灵石，一株能结三到七朵花。十分娇弱，不能离了人小心侍弄。[4] |
| 寸葛草 | 灵草 | 二阶极品 | 燕归门 | 百年只能长一寸，一根尺把长的这种草木，被燕归门修士连根粗鲁拔起，喜滋滋收入囊中。[16] |
| 鬼面黑水藤 | 木妖 | 四阶 | 展仇 | 展仇法宝双珠转心壶内黑河水那半边的器灵[17]，被风息归土兽吞噬[18]。 |
| 长生苔 | 苔藓 | 四阶 | 齐休、人面纹蛇 | 闪现微弱毫光的翠绿苔藓，可以增加五十年阳寿的大还丹主药之一，被人面纹蛇千万年守护在石台上[19]。赵瑶、奈文霖因此容颜不减[20]。齐休曾大量服用，并以之压制血手印腐蚀之力，致使很多以长生苔为主要成分的延寿丹药，如大还丹、小还丹之类已经无效[21]。因长生苔被霍鹳连根铲走，人面纹蛇决定往南迁徙[22]。 |
| 影木妖 | 木妖 | 五阶 | 楚无影 | 楚无影法宝万影阁的器灵，威能几乎同阶顶级[17]。相对来说是常用之物，有前人经验在，方便摸透运用法门[23]。 |
| 漆山岛花妖 | 花妖 | 五阶 | 齐休 | 漆山岛花妖木元素生命之力精纯至极。主干乃魔化前的精华部分之一，丈许长碗口粗的焦黑原木，被齐休炼入法宝莽古通明枪。对阵时可随时疗补自家伤势，是打持久战的好法门。[24][25][26] |
| 沙棘草 | 灵草 | — | — | 原著以此解释本命与灵根。[27] |
| 养魂木 | 灵木 | — | 秦唯喻 | 桢林门原林家开山老祖的本命[28]。北丁申山鬼修以养魂木质地的条状木匣封存秦唯喻等人魂魄[29]。 |
| 乌心荷花 | 植物 | 无阶 | 香蒲猪鱼 | 香蒲猪鱼喜欢呆在污浊恶臭之地，专吃相同环境下生长的乌心荷花根部[30]。乌心荷花虽然生命力极强，但在黑河中，就算预先加持过御兽门独有的木属性秘法，一百颗种子也不一定能长成一株活着的幼苗[31]。乌心荷花能改善土质，百余年坚持下来，昔日污臭黑雾只在盛夏时节还有些残余景象[32][33][34]。 |
| 魔阴树 | 魔树 | — | 血刀 | 以魔血浇灌种子长成，通体漆黑，可以正面硬抗金鼓烈阳[35]。断绝魔血供给，立刻散灭[29]。 |
| 食人花妖 | 花妖 | — | 楚无影 | 夺丹试炼中，一只巨大的金丹初期修为食人花妖从地底钻出。绿色主干上，长着一朵巨大的吊钟型花朵，上面有个盖子一开一阖。斑斓色彩之中，有两个对称的黑色圆环，像人的眼睛。被楚无影斩断花妖主干所杀。[36] |

| 血罟根 | 植物 | 无阶 | 血刀 | 地面以上只有薄薄一层地衣，地下根系十分发达，互相之间如渔网一般交缠联通，其内部贮有微量血液。有这种植物血引遁无处不可去。木败毒是其克星。[39] |
