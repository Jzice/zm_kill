# 丹药资料整理

## 一、按品阶汇总

- **无阶**：香薏丸
- **一阶**：回春丹、清心丹、小真源丹、回血丹、筑基丹、烈炎丹、回气丹
- **二阶**：豹胎玄极丹、真源丹、幻梦丹
- **三阶**：玉露玄极丹、劫尘丹、三才培元丹、黑凤丹、小还丹、森风聚元丹
- **四阶**：大还丹、增寿圣药
- **？阶**：结丹圣药、有器灵丹药

## 二、按用途速查

- **疗伤/解毒/恢复**：回春丹、回血丹、回气丹、香薏丸、清心丹
- **修为/境界辅助**：小真源丹、真源丹、筑基丹、豹胎玄极丹、烈炎丹、幻梦丹、结丹圣药、玉露玄极丹、劫尘丹、三才培元丹
- **延寿**：小还丹、大还丹、增寿圣药、森风聚元丹
- **特殊战斗/奇物**：黑凤丹、有器灵丹药

## 三、关键注意点

- **筑基丹**：一阶极品，但练气期炼丹师无法炼成；使用次数越多效力越小。
- **三才培元丹**：可增金丹修为五至十五年，一生只能服一枚；需三木同心本命修士方可炼制。
- **大还丹**：延寿约五十年，但对曾大量服用长生苔者无效。
- **结丹圣药**：可辅助结丹，但此生与结婴无缘。
- **森风聚元丹**：增寿八到十二年，每人只能一粒，服后需受森风戮体四十九天且妨碍晋阶。
