# 灵兽资料整理

## 一、简介

古兽一般生命极其悠长，进阶路数又和人类绝然不同，所以元婴实力存在，大多也就占个三阶灵地就够用了。

当年白山深处的那只化神母象，所占据的灵地，也就是如今丹盟的山门所在，也不过只有四阶而已。[1]

> 说明：原文标题含“按品阶”“按种类”“按境界”，正文仅按品阶列出名称，并在“灵兽一览表”中提供种类、品阶、境界、相关字段。以下据原文汇总，未标注字段以“—”表示，不另行编造。
