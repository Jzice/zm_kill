# 万物归沙阵

## 概述
万物归沙阵是一种三阶上品土系法阵，由三千余年前齐云派一位会空间法术的前辈大能设置，用于伏击化神级墨蛟。在黑河地底遗迹中运转千余年后已近崩溃，最终被楚神亭以三阶飞剑破除。

## 属性/效果
- **品阶**：三阶上品
- **属性**：土系
- **功能**：以沙土元素构成屏障，困锁目标于阵内空间。千余年后阵法已运转至崩溃边缘，沙土元素到处飞散，造成视线与呼吸受阻。
- **弱点**：阵法运转千年后多处薄弱，向外散逸沙土之力形成沙眼孔洞（导致外面灰蒙蒙）。有固定阵眼，知晓阵法者可定位并逐一破除。
- **破解方法**：以木系威能克制土系（利用五行相克原理），在护罩薄弱处撑出可通过的洞口而不触发防护手段。

## 持有者/使用者
- **设置者**：齐云派前辈大能（三千余年前），用于在死亡沼泽空间通道中伏击化神墨蛟。
- **破阵者**：楚神亭（金丹后期）携两名齐云楚家阵法大师，在遗迹探索中识别并破除此阵。

## 核查记录
- 万物归沙阵是为伏击墨蛟而设，伏击地点位于死亡沼泽地底空间通道中。
- 三千多年前齐云等超级宗门追杀化神墨蛟，一位会空间法术的前辈大能造出空间通道连接自然空间裂缝，在墨蛟穿行中途设伏击杀。
- 这样的伏击点共有十好几处，后来都已撤离干净，唯此处因不明原因又出现大阵踪影。
- 楚神亭两名阵法大师能辨识阵眼并破阵，显示其阵法造诣极高。
- 阵法大师以罗盘和特殊器具勘探阵眼，楚神亭用三阶飞剑逐一破除。
