# 心生蜂云剑

## 概述
心生蜂云剑是一套三十六把二阶极品飞剑，由古熔、莫剑心与古铁生以火炼水炼交替之法联合打造，专为齐妆的本命天赋与【蜂云剑阵】量身定制。齐妆以此剑布开蜂云剑阵第四层，威力可敌金丹以下任何修士。

## 属性/效果
- **品阶**：二阶极品
- **数量**：三十六把（品质如一）
- **属性**：【坚固】【锋锐】【自疗】【同心】【幻月】【鎏花】【分水】【分火】【连环】（九属性）
- **水火同济**：水火双属性交替攻击，冰火连环，令对手应接不暇
- **技能**：无独立技能，配合齐妆本命天赋【剑影分光】使用
- **剑阵效果**：
  - 蜂云剑阵第四层：一百零八把飞剑（三十六把本体分光为三），金丹以下难以抵挡
  - 可同时布开三个三十六柄蜂云三层小阵
  - 可布三十六个九剑蜂云一层剑阵
  - 可布十二座九剑蜂云一层剑阵游移补漏（配合奉剑灵狐器灵）

## 持有者/使用者
- [[角色/齐妆]] — 唯一使用者。齐妆为楚秦门长老，单剑匣本命天赋，筑基后领悟【剑影分光】（一剑化四），配合蜂云剑阵第三层时已有极强战力，装备心生蜂云剑后更上一层楼。
- 齐妆此时为金丹修为（金丹级战力）。
- 现持有七柄心生蜂云剑（ch371中提及齐妆在醒狮谷后只剩七柄）。
- 炼制者：古熔（火炼）、莫剑心（水炼）、古铁生（辅助）。
