# 命隐符

## 概述
命隐符是一种一阶特殊符篆，能够隔绝各种命运法术的探查，使预言、回溯类法术或本命天赋在符篆有效范围内失效。由齐休根据齐云道书所载方法自行制备，与齐休的赤尻马猴本命相关。

## 属性/效果
- **品阶**：一阶符篆
- **效果**：使用后在很小范围内持续约四分之一炷香时间，隔绝命运法术的探查（同阶有效）。
- **原理**：与齐休赤尻马猴本命的"晓阴阳、避死延生"特性有关。老掌门推测赤尻马猴本命可能与命运之力存在关联，故齐休能制备此符。
- **制作要求**：需严格限定的各种天赋方可制作，极其冷门。
- **外观**：符面纹绘乱七八糟，乾坤不明、阴阳混乱，似卦而非卦，如小孩涂鸦，但灵力做不得假。

## 持有者/使用者
- [[角色/齐休]] — 楚秦门掌门。齐休早年在黑河时曾制备命隐符托余德诺在白山售卖贴补家用，后不再出售。
- 宁家与奈文家曾弄到白山市面上流转的命隐符，在符篆之力生效期间秘密缔结对付楚秦门的盟约，导致齐休的【心血来潮】天赋完全无感应，险遭暗算。

## 核查记录
- 命隐符为齐休从齐云道书中学得的冷门制符之术，与赤尻马猴本命相关。
- 白山市面上命隐符已流通数十年，来源不限于齐休制作。
- 宁家与奈文家利用命隐符的【不在算中】之力，使齐休的【心血来潮】天赋完全失效。
- 齐休制符时会在不显眼处留"楚秦齐休"密记，但余德诺提醒此做法有暴露根脚的风险。
- 此符为一阶符篆，只能隔绝同阶命运法术。
