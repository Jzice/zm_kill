# 猴面金身法像

## 概述
猴面金身法像是一对三阶法器，以猴面金身造型铸成，具有极高的防御力（极坚固属性），可用于抵挡飞剑攻击。原为齐休持有的一对独立法器，后被古熔拆解为棒头，与如意精金棒身结合，锻造成三阶中品法器【如意三花棒】。

## 属性/效果
- **品阶**：三阶
- **数量**：一对（两件）
- **属性**：【极坚固】
- **功能**：防御型法器，可抵挡飞剑攻击。两件合一使用，为齐休的主要防御手段之一。
- **后续演变**：古熔将两件猴面金身法像作为棒头，以如意精金为棒身，打造出如意三花棒。合并后猴面金身法像的属性融入新法器，如意三花棒额外获得【镇邪】【威压】【克土】【极沉重】等属性，以及【召唤双猿】（两只筑基初期冰猿虚影）和【天地三花】技能，威力倍增。

## 持有者/使用者
- [[角色/齐休]] — 楚秦门掌门。齐休在稷下城被袭击时以猴面金身法像抵挡姚青的飞剑。后来古熔将其重铸为如意三花棒，齐休以此棒配合【金刚真言棒法】和【哼哈真言】使用。
- 古熔 — 离火盟古剑阁炼器大师，负责重铸工作。以两件猴面金身法像为棒头，配合如意精金打造出如意三花棒。

## 核查记录
- 猴面金身法像在稷下城时仍为独立法器，齐休以"来不及祭出"的描述使用，说明其需要一定时间催动。
- 古熔重铸如意三花棒是作为离开楚秦门前的补偿（因提前终止十年教习之约）。
- 如意三花棒的【召唤双猿】技能源自猴面金身法像的原始属性，升级为可召唤两只筑基初期冰猿虚影。
- 如意三花棒的【天地三花】技能可发出上下共六朵奇花进行防御，在楚秦门灭刘家之战中曾挡住金丹散修的判官笔攻击。
- 齐休配合如意三花棒使用的棒法为二阶下品【金刚真言棒法】，共十八打，但齐休往往前两打就解决问题。
