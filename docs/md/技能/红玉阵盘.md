# 红玉阵盘

## 物品画像

楚秦山护山大阵【十方风火归元大阵】的控制阵盘之一（主控炎火威力增幅），由秦斯言在告别楚秦山时归还给齐休。南迁元年被齐休以十五块三阶灵石的价格卖给流花宗。

## 物品特点

- 楚秦山护山大阵【十方风火归元大阵】的控制阵盘之一
- 与风系阵盘配合，火借风势可使【十方炙炎】威能倍增
- 为齐云派传承阵法，只有金丹修士才可制作
- 持有此阵盘的一方在交易中处于有利地位（楚秦门只有此一块阵盘）
