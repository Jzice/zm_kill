# 幻影夺心刺

## 概述
幻影夺心刺是莫剑心在筑基时偶然炼成的二阶极品飞剑，以三相精金为底、幻月银丝纹为饰，三棱剑身，自带【三相夺心】技能，可夺取对手心志。莫剑心以此剑为本命法器，后用于楚秦山之战中配合齐休对付奈文落。

## 属性/效果
- **品阶**：二阶极品
- **五属性**：【幻月】【三相】【坚固】【极锋锐】【绝影】
- **技能**：【三相夺心】——使中招者表情大变，仿佛看到极恐怖之物，心志被夺，短时间内无法正常战斗。
- **外形**：三棱剑身，三相精金为底，上镶幻月银丝纹，奇细长的剑身在剑尖上收束，护手为银色弯月，剑柄同为金底银丝。

## 持有者/使用者
- [[角色/莫剑心]] — 楚秦门长老，炼剑大师。莫剑心在古熔帮助下以火炼三相精金剑胚、水炼两年而成此剑，炼成之时恰逢筑基契机，一举突破。

## 核查记录
- 莫剑心在中秋月圆之夜筑基成功，筑基异象为一轮刺目幻月当空。
- 筑基异象中出现金银交错三棱刺飞剑虚影，即为此剑的本命显化。
- 在楚秦山之战中，莫剑心以此剑配合齐休对付奈文落，【三相夺心】一度令奈文落心志被夺，被敢毅趁机进攻。
- 奈文落后来佩戴指环法器防御心志攻击，齐休再次使用哼哈真言时被抵挡。
- 莫剑心还有一项新天赋【幻月悲歌】，可拉人进入悲伤回忆。
