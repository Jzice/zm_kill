# 七彩幻珑蛇

## 概述
七彩幻珑蛇是一只二阶极品灵兽，拥有极强的幻化能力，可变幻为各种天地灵兽、鬼怪、魔物等形态。在高广崧遗迹中被齐休收服，成为齐休的灵兽，在楚秦山之战中幻化为金甲乐傀形象，成为压垮敌方士气的决定性一击。

## 属性/效果
- **品阶**：二阶极品
- **能力**：幻化——可变幻为各种形态（魔蚓、天地灵兽、鬼怪、魔物等），形貌极为逼真，但被【破幻之眼】类天赋可轻易识破。
- **弱点**：灵智有限，变幻后若对手观察仔细（如注意地上无爬行痕迹），可辨别真伪。在空间通道中能以灵魂信息求救/魅惑。
- **灵智**：能传递灵魂信息（求饶、投靠等），但整体灵智不高。

## 持有者/使用者
- [[角色/齐休]] — 楚秦门掌门。齐休在高广崧遗迹三楼发现七彩幻珑蛇，其正以幻化魔蚓形态守护高广崧遗骨。齐休以【破幻之眼】识破后，识海中的赤尻马猴本命越过齐休答应了蛇的投靠，七彩幻珑蛇遂成为齐休灵兽。
- 在楚秦山之战中，齐休心神联系七彩幻珑蛇，令其幻化为三阶金甲乐傀形象（十丈高，一手金锣一手金锤），给奈文家修士造成致命的心理打击。

## 核查记录
- 七彩幻珑蛇原本守护高广崧遗骨，已在此千年。
- 其幻化魔蚓形态时，齐休通过观察地上尘埃无爬行痕迹而识破。
- 齐休尝试以佛光攻击时蛇已求饶，赤尻马猴本命主动越过齐休答应投靠。
- 在楚秦山之战中，蛇幻化的金甲乐傀比正牌小了好几号，但足以击溃敌方士气。
- 蛇平时蜷在齐休头发里，齐休事后才摸到，说明其体型极小。
