**选词规则**
1. 基本牌：攻击 / 闪避保留三国杀原名「杀 / 火杀 / 雷杀 / 闪」（核心动作术语）；桃 → **回春丹**、酒 → **真源丹**。
2. 锦囊：核心机制类沿用「**决斗**」；其余取自 功法(B) / 技能(K) / 符箓(C) / 本命天赋 / 原著灾劫。
3. 兵器类词条**只作装备**，不作锦囊；**阵法可作防具**（也可作锦囊）。
4. **载具**为新增装备类，取代 ±1 马。
5. 身份：**掌门 / 弟子 / 邪修 / 黑手**。

## 2. 修真资源层

### 2.1 灵石（L-灵石.md）

- 上限 8（溢出作废）；回合开始 +1；每块灵地按阶产出（占领 >2 块后每块 -1，最低 1）；击杀 +2。
- 消耗：坊市（3 灵石摸 1 张，每回合限 1 次）、境界突破、开辟灵地（2 灵石）、红玉阵盘抵消伤害。
- 灵石不可被抢夺。

### 2.2 修为与境界突破（L-修行体系.md）

修为：造成伤害 +1 / 击杀 +2 / 救活 +1 / 占领灵地 +1。

| 境界 | 灵地 | 灵石 | 修为 | 效果 |
| --- | --- | --- | --- | --- |
| 筑基 | 一阶 | 3 | 4 | 上限 +1、回 1 |
| 金丹 | 三阶 | 6 | 8 | 上限 +1、回 1 |
| 元婴 | 五阶（无则三阶 ×2 + 额外 4 灵石折算） | 10 | 12 | 上限 +2、回 2 |

每局最多突破 2 次；单本命修为需求 -1，双本命 +1（本命越多灵根越杂，修炼越慢但天赋更强）。

### 2.3 本命 / 灵根（L-本命.md）

- 每名角色带 `benming`（1~2 个），对他人隐藏；阵亡或被【全知天眼】探查后公开。
- 探听本命即结怨：被探查者对探查者敌意 +1（AI 记仇）。

### 2.4 家族血脉（L-修士血统论.md、L-大周书院宗法制.md）

角色带 `family`（齐 / 秦 / 楚 / 展 / 熊 / 莫 / 南宫 / 龙 / 霍 …），为「族会」等后续机制预留。

### 2.5 器灵成长（N-法器属性设定.md）

兵器法宝带器灵层数：造成伤害累积，达 3 层攻击范围 +1，达 6 层伤害 +1；被破阵符弃置时清零。

### 2.6 夺舍（黑手专属，L-夺舍.md）

黑手（spy）阵亡时若手牌 ≥2，可弃全部手牌宣告夺舍一名存活角色，转为该角色阵营继续游戏；每局限 1 次。
（原著：多罗诺以散魂棺夺舍；黑手为隐于幕后的秘密组织。）

## 6. 实施说明

- **零回归**：经典模式 `buildDeck` 走原路径逐字不动；修真牌堆 `sub` 全部复用现有引擎 key，
  出牌 / 判定 / 无懈响应链 / AI 分支均无需改动，仅换卡名与副题。
- **新增文件**：`src/core/mode.ts`、`src/data/zml/{cards,characters,skilldefs}.zml.ts`、`src/game/zml/economy.ts`。
- **修改点**：`types.ts`（修真类型 + Card.subtitle）、`cards.ts`（buildZmlDeck）、
  `skilldefs.ts`（合并原著技能表）、`setup.ts`（按模式装配）、`turn.ts`（灵石产出 + 出牌阶段修真行动）、
  `actions.ts`（5 张原著机制卡 + 通天令）、`rules.ts`（储物袋）、`damage.ts`（玄水归土阵 / 红玉阵盘 / 击杀收益）、
  `skillEngine.ts`（通明身识）、`render.ts`（身份名 / 境界条 / 灵地盘 / 载具文案）、
  `lobby.ts` + `index.html`（模式选择器）、`protocol.ts` + `network.ts`（mode / grounds 同步）。
- **未做**（留待后续）：开辟战争分队与灵地胜负判定、家族「族会」、器灵成长、飞蟹载客、夺舍交互。
