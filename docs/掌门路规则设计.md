# 掌门路规则设计（v0.1.0 定稿）

> 目标：把「掌门杀」从「原版身份推理卡牌 + 名人皮角色」改造为**贴合《修真门派掌门路》原著的卡牌与规则体系**。
> 所有卡牌名、机制名均出自 `docs/`（出处代号见下表）；确需引申时，基于功法 / 技能 / 符箓的真实特性派生，不牵强附会。

## 0.1 术语体系（v0.1.0 重构）

| 现术语 | 原术语 | 说明 |
| --- | --- | --- |
| **技能** | 锦囊 | 打出即结算、进弃牌堆的卡牌。掌门路（zml）仍显示「锦囊」 |
| **天赋** | 角色技能 | 角色卡自带的本命能力，每人 2~3 个 |
| **法宝** | 宝物 | 持续生效的卡牌；**不是独立槽位**，按攻防特性装备进**武器槽**（进攻型）或**防具槽**（防守型） |
| **+1 载具 / -1 载具** | +1 马 / -1 马 | 载具法宝或灵兽 |

**角色卡结构**：名称 + 身份（掌门 / 弟子 / 邪修 / 黑手）+ 血量 + 2~3 个本命天赋 + 四装备槽（武器 / 防具 / +1载具 / -1载具）。

**本命**只作角色卡的隐藏信息字段（`benming: string[]`），不卡牌化、不占槽位；阵亡或被【全知天眼】探查后公开。

**拆分原则**：技能密度高的角色，其次要天赋剥离为通用卡牌——持续型做成**法宝**（进武器或防具槽），瞬时型做成**技能**（打出即结算）；角色本身只保留 2~3 个核心**天赋**。

**选词规则**
1. 基本牌：引擎 key 保留 sha / huo / lei / shan / tao / jiu，卡名按功能拆为修真变体——杀 / 火杀 / 雷杀 → 攻击功法·符箓·法宝，闪 → 身法·盾法，桃 → 恢复丹药，酒 → 增益丹药·符箓（各 sub 总数不变）。
2. 锦囊：核心机制类沿用「**决斗**」；其余取自 功法(B) / 技能(K) / 符箓(C) / 本命天赋 / 原著灾劫。
3. 兵器类词条**只作装备**，不作锦囊；**阵法可作防具**（也可作锦囊）。
4. **载具**为新增装备类，取代 ±1 马。
5. 身份：**掌门 / 弟子 / 邪修 / 黑手**。

## 2. 修真资源层

### 2.1 灵石（L-灵石.md）

- 上限 8（溢出作废）；回合开始 +1；每块灵地按阶产出（占领 >2 块后每块 -1，最低 1）；击杀 +2。
- 消耗：坊市（3 灵石摸 1 张，每回合限 1 次）、境界突破、开辟灵地（2 灵石）、红玉阵盘抵消伤害。
- 灵石不可被抢夺。

### 2.2 修为与境界突破（L-修行体系.md）

修为：造成伤害 +1 / 击杀 +2 / 救活 +1 / 占领灵地 +1。

| 境界 | 灵地 | 灵石 | 修为 | 效果 |
| --- | --- | --- | --- | --- |
| 筑基 | 一阶 | 3 | 4 | 上限 +1、回 1 |
| 金丹 | 三阶 | 6 | 8 | 上限 +1、回 1 |
| 元婴 | 五阶（无则三阶 ×2 + 额外 4 灵石折算） | 10 | 12 | 上限 +2、回 2 |

每局最多突破 2 次；单本命修为需求 -1，双本命 +1（本命越多灵根越杂，修炼越慢但天赋更强）。

### 2.3 本命 / 灵根（L-本命.md）

- 每名角色带 `benming`（1~2 个），对他人隐藏；阵亡或被【全知天眼】探查后公开。
- 探听本命即结怨：被探查者对探查者敌意 +1（AI 记仇）。

### 2.4 家族血脉（L-修士血统论.md、L-大周书院宗法制.md）

角色带 `family`（齐 / 秦 / 楚 / 展 / 熊 / 莫 / 南宫 / 龙 / 霍 …），为「族会」等后续机制预留。

### 2.5 器灵成长（N-法器属性设定.md）

兵器法宝带器灵层数：造成伤害累积，达 3 层攻击范围 +1，达 6 层伤害 +1；被破阵符弃置时清零。

### 2.6 夺舍（黑手专属，L-夺舍.md）

黑手（spy）阵亡时若手牌 ≥2，可弃全部手牌宣告夺舍一名存活角色，转为该角色阵营继续游戏；每局限 1 次。
（原著：多罗诺以散魂棺夺舍；黑手为隐于幕后的秘密组织。）
